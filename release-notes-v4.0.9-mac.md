gary4juce v4.0.9-mac adds an optional wide mode for our friends who hate scroll bars. Open gary settings with the gear button to switch between wide and compact layouts, and the plugin remembers which one you picked.

That gear button replaces the storage button from v4.0.8-mac. Moving the `gary4juce` audio folder now lives inside the same settings menu.

If the current layout works fine for you, you can go ahead and skip this update.

All three downloads contain universal x86_64/arm64 binaries and include the project license, third-party notices, and exact Corresponding Source information. The AU and VST3 retain their familiar Gary Finder icon.

This release is paired with [gary4local mac v0.2.0](https://github.com/betweentwomidnights/gary-localhost-installer-mac/releases/tag/v0.2.0).
